# PriceWhy
### 가격의 이유를 분석하는 AI 쇼핑 어시스턴트

**Team NICHE | 비즈니스동향 팀 프로젝트**

PriceWhy는 여러 쇼핑 상품을 동일한 기준으로 비교하고, AI 분석을 통해 소비자의 합리적인 구매 결정을 돕는 Chrome 확장 프로그램입니다.

## 주요 기능
- 쇼핑몰 상품 담기 및 비교
- 구매 목적에 따른 비교 기준 선택
- AI 기반 상품 비교 리포트 생성
- 비교 리포트 저장 및 재확인

## 서비스 체험하기

**[PriceWhy 공식 홈페이지](https://team-niche.github.io/)**

홈페이지에서 확장 프로그램을 다운로드하고, 이미지로 제공되는 설치 가이드를 따라 체험할 수 있습니다.

※ AI 분석 기능을 사용하려면 별도의 API 키가 필요합니다. 체험용 API 키는 발표 시간에 안내됩니다.

## 프로젝트 이용 안내

본 프로젝트는 대학 수업 시연 및 평가 목적으로 제작된 프로토타입입니다.

수업 시연 및 평가 목적 외의 무단 복제·재배포·상업적 이용을 허용하지 않습니다.

PriceWhy는 쿠팡·네이버와 공식적으로 제휴하거나 해당 서비스를 대표하지 않습니다.

API 사용량 및 과금 여부는 이용자가 직접 확인해 주세요.
